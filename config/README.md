# Config files

This file contains non-essential customization settings.

Tweak some of these to tweak certain bot behavior!

This is an attempt to make the bot less "hardcoded" in a sense lol

API: Stuff to do with external APIs (NexAPI is one)
Core: Stuff to do with the core of the Discord bot, including some essential Discord stuff
Fun: Stuff to do thats fun! Change these as you wish
Essential: probably don't change this lol
Mod: Moderation controls
Visual: Stuff to do with the bot's visual identity.
