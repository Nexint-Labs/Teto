# Legacy Code

This directory contains archived implementations of Prism and its predecessor projects.

These files are preserved for historical and educational purposes, allowing contributors to explore how the bot's architecture, commands, and utilities evolved over time.

**The code in this directory is not actively maintained and should not be used in production.**

For current implementations, refer to `functions/v2/` and `plugins/`.

Legacy code may depend on outdated APIs, dependencies, or configuration structures.
